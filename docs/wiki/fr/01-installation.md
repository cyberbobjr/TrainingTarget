# Installation

1. Abonnez-vous à **Training Target - Shooting Range & Training Dummy** sur le Workshop Steam (objet 3810261246).
2. Dans le sélecteur de mods du jeu, activez **batman_Training Target** (`batman_TrainingTarget`). Le mod exige la Build 42.21 ou plus récente.
3. Facultatif : activez **batman_Training Target - Viewpoint models** (`batman_TrainingTargetViewpoint`) seulement si vous utilisez aussi [Project Viewpoint](https://steamcommunity.com/sharedfiles/filedetails/?id=3809306528). Il ajoute les modèles 3D des cibles, des états du mannequin, des trous et des conserves ; sans Project Viewpoint, il ne fait rien.
4. Lancez ou chargez une partie. La page sandbox **Training Target** règle le mod (voir [Options](04-options.md)).

Sur un serveur, ajoutez `batman_TrainingTarget` à `Mods=` et `3810261246` à `WorkshopItems=` (voir [Multijoueur](05-multijoueur.md)).

> Capture à faire : sélecteur de mods avec batman_Training Target activé.

Compatible avec [SVRP] ClassicBows : ses arcs et arbalètes comptent sur les cibles d'entraînement.
