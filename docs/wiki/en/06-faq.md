# FAQ

**My shot does not count.**
Check that you hold an aimed firearm, that you are at least 3 tiles away (option), on the same floor, within the weapon's range, and in front of a wall target. A sheet that is shot to pieces or an empty can stand blocks training until maintenance ([Placing and using targets](02-placing-and-using-targets.md)).

**The aim circle stays grey.**
The coloured circle is drawn only with the mouse, when the shot would count, and only if the aim circle is enabled in the game options. With a gamepad, only the valid-target reticle is shown.

**Can I put anything on the can stand?**
No: only empty cans, up to the "Cans on the stand" option.

**My fists do not train on the dummy.**
Bare hands and weapons without a melee category give no experience.

**Can the dummy break?**
Player blows never destroy training furniture. The dummy only wears out and must be repaired (hammer, plank, 2 nails).

**My statistics disappeared.**
A session ends after the "Session timeout" option without a shot, when you start a new session, when you quit a solo game, or when the server restarts.

**Do bows work?**
Bows and crossbows of [SVRP] ClassicBows count like firearms. The arrow's flight is not tracked: the shot is judged when it is fired.

**Do I need the Viewpoint models mod?**
Only if you use Project Viewpoint.
